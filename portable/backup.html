Cadangan data komputer

Simpan transaksi, stok, master data, kereta, dan riwayat dari browser ini ke file JSON.

Memeriksa sesi…

1. Simpan cadangan

Unduh setelah selesai testing dan sebelum pindah komputer atau membersihkan data browser. Tunggu semua transaksi selesai tersimpan.

2. Pulihkan cadangan

Pemulihan mengganti seluruh data WMS di browser ini. Tutup tab WMS lainnya terlebih dahulu. Cadangan data saat ini akan diunduh sebelum penggantian.

Data versi online berada di alamat browser yang berbeda dan tidak otomatis masuk ke paket ini. File cadangan hanya memindahkan data, bukan PIN login komputer.
